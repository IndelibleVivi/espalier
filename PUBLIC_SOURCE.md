# Public source boundary

This tree is a clean source projection from a private development incubator. It intentionally contains the general Espalier product, canonical semantics, local service, CLI/client adapters, Codex Skill, canonical project-neutral live Canvas renderer, tests, CI, and bilingual public documentation.

It intentionally excludes private working continuity, project-specific dogfood applications, private source snapshots, experimental design evidence, screenshots from non-public projects, local runtime state, and the incubator's Git history.

Test-only project, actor, device, and prose vocabulary inherited from private dogfood is deterministically normalized to neutral public examples during export. The command and projection contracts, fixture topology, assertions, and executable behavior are unchanged, and the exported tests are rerun from the clean tree.

The projection is a content boundary, not a release receipt. Project-original functional source is mapped to `SUL-1.0`; covered original documentation is mapped to `CC BY-NC-SA 4.0`; dependencies retain their own terms. See the public repository's [`LICENSING.md`](https://github.com/IndelibleVivi/espalier/blob/main/LICENSING.md) and [`THIRD_PARTY_NOTICES.md`](https://github.com/IndelibleVivi/espalier/blob/main/THIRD_PARTY_NOTICES.md). Publication still requires a clean-tree secret/privacy/rights review, green source and hosted CI gates, and owner authorization for the exact public commit.
